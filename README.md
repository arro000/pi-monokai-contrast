# Monokai Contrast for Pi

A high-contrast Monokai-inspired theme for [Pi](https://pi.dev).

## Install

Copy `monokai-contrast.json` into Pi's themes directory (usually `~/.pi/agent/themes/`), then select it in `~/.pi/agent/settings.json`:

```json
{
  "theme": "monokai-contrast"
}
```

Or select it from Pi's theme picker if available in your version.

## Colors

Dark background with Monokai green, yellow, cyan, pink, purple, and orange accents. Secondary text is white for readability; the palette is checked for WCAG AA contrast (4.5:1) across the main surfaces.
